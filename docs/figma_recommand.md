有，**但严格说没有一个“完全像菜鸟教程那样、中文、章节化、长期更新且权威”的 Figma 教程站**。我会这样推荐：

**首选：Figma 官方学习中心**  
[Figma Learn / Help Center](https://help.figma.com/hc/en-us/categories/360002042553-Figma-Design)  
最值得从这里开始。它不是中文菜鸟教程风格，但结构最完整，覆盖界面、图层、Frame、Auto Layout、组件、Variables、Design System、Dev Mode、MCP 等。官方文档里已经把 `Auto layout`、`Components`、`Variables`、`Dev Mode`、`Figma MCP server` 都分成了独立模块。  
适合你这种“想把 Figma 用到可维护代码生成里”的学习目标。

**设计基础：Figma Resource Library**  
[Figma Design Basics](https://www.figma.com/resource-library/design-basics/)  
这个更偏 UI/UX 基础，适合补“为什么这么设计”，比如 UI/UX 区别、字体、布局、设计原则。它不只是教按钮在哪里，而是补设计判断力。

**中文内容：优设网 Figma 频道**  
[优设网 Figma 专题](https://www.uisdc.com/tag/figma)  
优设网不是菜鸟教程那种线性课程，但中文内容多，适合查技巧、插件、设计系统、国内团队经验。页面显示它有持续更新的 Figma 内容，并且覆盖插件、技巧、组件库、入门教程等方向。

**进阶：Design+Code 的 Figma / Design System 课程**  
[Design+Code: Design System in Figma](https://designcode.io/figma/)  
这个适合你后面学“Figma 如何服务工程化”。它的课程包含布局、约束、自适应、样式、团队库、组件嵌套、导出、Inspect、代码交付等内容。缺点是英文为主，部分内容可能付费。

我的建议学习路线是：

1. 先学 Figma 官方：Frame、Auto Layout、Constraints、Components、Variants。
2. 再学 Styles / Variables / Design Tokens。
3. 接着学 Design System：按钮、输入框、表格、弹窗、导航、状态管理。
4. 最后学 Dev Mode、Code Connect、Figma MCP，把设计数据交给 AI 或工程代码。

如果你是为了“AI + Figma + 前端代码生成”，重点不是把 Figma 所有功能都学完，而是优先掌握这几个：**Auto Layout、组件/变体、Variables、样式命名、响应式约束、Dev Mode 标注**。这些才是从设计到可维护代码的硬通货。
